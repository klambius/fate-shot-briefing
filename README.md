# FATE//SHOT — интерактивный анонс

Откройте `index.html` в браузере. Клик по сцене или Enter открывает очередную часть брифинга.

Для фоновой музыки скопируйте MP3 в `assets/mission.mp3`. Регулятор громкости и mute уже подключены.

Сайт статический и готов для GitHub Pages: опубликуйте содержимое этой папки из корня ветки main.
